# Security Policy

## Supported Versions

Only the latest commit on the `main` branch is actively supported with security updates.

## Reporting a Vulnerability

If you discover a security issue or vulnerability in `db_git` (particularly concerning credential handling, DPAPI encryption, or database connection handling):

1. **Do not** report security vulnerabilities via public GitHub issues.
2. Please report the issue privately by emailing `kamutalamanisai26@gmail.com` with:
   - A summary of the vulnerability
   - Steps to reproduce or proof-of-concept
   - Impact assessment
3. You will receive an initial response within 48 hours acknowledging receipt.
